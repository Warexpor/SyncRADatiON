Run: `S=~/Unity/Hub/Editor/6000.6.0f1/Editor/Data/DotNetSdk; DOTNET_ROOT=$S $S/dotnet test tests/SyncRADation.Tests` (needs only the SDK + cached NuGet xunit 2.9.2 / Test.Sdk 17.11.1 / runner 2.8.2).

Blocked (not compiled here): `LanNetworkManager*`, `Networking/Dispatch`, everything in Domains/UI/Cheats (MelonLoader/Il2Cpp/Unity types), `Sync/Guard.cs` (MelonLoader logger; shimmed).
