# What is synced

Authority and behavior per area. Rows marked local are local by design (not parked work).

| Area | Authority | Notes |
|------|-----------|--------|
| Identity | Both peers | `WorldId` = hash(scene + hierarchy path), **pinned at scene load** (`Sync/WorldId` cache warmed by the scene scan): a native `Destroy` on one peer never shifts another object's id |
| Sync toggles | Host | `SyncPuzzles` / `SyncWorldPickups` / `SyncPlayerVitals` / `FriendlyFire` / `AllowClientCheats` are the host's (`PlayerRoster.HostFlags`); a connected client uses them, not its own cfg. Client F6 keys/objects, F7 loads and F11 spawns need `AllowClientCheats` (host rejects otherwise) |
| Avatar proxy + bones/weapons | Peer | ~25–30 Hz pose: root position + facing, weapon, flags, all 83 bone rotations + humanoid hips position. The proxy has **no Animator** (every Elster clip only drives humanoid muscles / root, which the bone + hips sync replaces). Per-sender scene check: a peer in another scene (wreck/hole split) has no proxy here; host relays pose only to peers in the sender's scene |
| Enemies | Host | WorldId snaps; **native TakeDamage**; client hits Harmony→host carry the HP the client's `PlayerAttack` took off (`EnemyDamage.Damage`), the host lowers `Hitbox.HP` by it, then native `TakeDamage`; host **wakes sleeping-chunk** enemies when a peer is near. Contact ram damage stays native. F11 spawn is host-authored (`EnemySpawn` + `SR_Spawn_*` WorldId); a lone host leaves native spawns untouched |
| Doors (double / sliding) | Any peer emit, host relay to everyone (incl. the sender) | Visual open/close via native methods; locked-door open block only in a party |
| ConnectedDoors (room links) | Lock only | **Never** sync traverse / StartA/B — room entry is local. Unique key doors: one solve (party key ring **Key/Object only**), both walk |
| Ladders | Local traverse | Climb is per-player; other peer only hears proxy SFX (no `Interaction.trigger`) |
| Chapter / scene load | Host | SceneFollow via `AsyncLoader` / `SceneHelper` / `LoadLevelZone` — int and string loads both gate. **Wreck↔hole never follows** (each Elster loads `PEN_Hole` when they finish the airlock). Host leaving Penrose still follows. Client F7 is a host load + follow, not `BeginApply`. Follow calls RestorePlay (clears inventory/menu sticky) before load |
| Story (SProgress, cutscenes, END_Manager) | Host | Full slot dump on join (read-only inside a unicast dump); incremental dirty-key commits; authoritative full commit after a host load keeps each client's per-player keys (minimap, radio frequency, slot); `memoryTime` is the host's clock. **Books / notes / EventScreen / EventOnlyRoom / airlock (`PEN_Titles`) stay local. Dialoguer is local**: every shipped dialogue is flavor, each player reads/skips/answers their own. Cutscenes: one start window (4 s) and one skip window (30 s, also blocks restarts); pause skips only a running cutscene. **Other-room cutscenes / EventZones do not Start/Invoke** on the observer; during the wreck/hole split a client runs its own scene's cutscenes natively. A client that missed the ending broadcast gets it re-sent |
| World FMOD | Host Play/Stop | StudioEventEmitter by WorldId (one per-scene emitter table); skip Elster + radio UI + **Music/Cutscenes/Ambience beds**; **far non-door Play** distance-gated like doors; tuner freq local. Applied sounds and one-shots play only if the emitter is in the local player's room (`FmodEmitterSync.AudibleHere`) or within 8 m; the host relays an applied emit / one-shot to everyone except the sender (`NetGate.ApplySender`) |
| Puzzles / locks / elevators / radio module / storage / event zones / alert | Host + client emit | **WorldId-keyed**; client emits puzzle/lock types only (not `Interaction.trigger` / EventZone / combat); apply **snaps flags + doors**, never EventScreen / `trigger()`; cryo/codepad/pump/pipes/hatch live-apply native Open/Drain/TurnValve; unlocked location doors stay open for the party; **GunCase / AraNest / LAB_RifleQuest / LOV_Microfiche** (protocol 10); **MED_Adler_EVdoors** DoorL/R local X (protocol 11); PatternLock grid + Tarot cards + LibraryPC robotPos mid-hold; mural late-join Blocker snap (no cutscene replay); biodome KeyLevel + MultiCondition tried mid-hold |
| Live shared puzzle screens | Host merge, every peer replays | Two players in the same zoom-in puzzle see each other's input as it happens. Keypads (Keypad3D, ROT_Keypad, PEN_Codepad) share one typed code; each press replays through the native coroutine (button push / wheel flip / red blink) via `Locks/KeypadLive`. Pattern lock / key grid merge per light, tarot per slot, keypads + evidence locker whole (`PuzzleSyncService.IsMergeType`); the host relays merges to everyone and a client skips stale echoes of its own presses. Press sounds (`PuzzleFx`): native 2D for a player zoomed into that screen, 3D at the room-side panel with door falloff for anyone else in that room, silent elsewhere. Incinerator knobs/curve, elemental card locks, pump pressure colour, card-writer cursor and library robot glide are redrawn by the mod (no native redraw) |
| Host disconnect | Client goes offline | Restores play + input; clears enemy/boss puppets, EventZone/cutscene/airlock/SceneFollow sticky |
| World ItemPickups | Host claim/grant | Claimer gets item; unique **Key/Object** go on the **party key ring**; ammo/docs do not. A partial take (bag can't hold the stack) releases the claim and every peer's prop shows the remainder (`WorldPickupEntry.Count`). A taken prop never comes back when its taker leaves. Client bag keys still unlock UseItem (hatch card). **TarotDeath** held while live unclaimed **KeyOfSacrifice** (NG+ Artifact softlock); a vetoed take resets the prop's `triggered`. Ring masquerade (`hasItem`/`getCount`) is off inside native `ItemPickup.release` (`ItemPickupTakeScope`) and `SaveManager.Save`; ring keys are never added to a bag physically |
| Player-dropped items | Peer + relay | G or inventory **DROP**; floor snap; native TAKE inspect (yes/no + count) then grant of what the bag actually takes (overflow spills back to the floor); join dump; **peer-gone mid DroppedPickup / StorageTake rejected** (floor/box kept; Put still applies); an in-flight put at session end stays boxed |
| Death | Asymmetric | Client downed (ammo/docs floor bag; **all Key/Object Note onto party ring, never floor**); native `HurtElster` HP; host death `SaveManager.Load` for both |
| Bosses (END / Chimera / Mynah / Kolibri / Adler) | Host | `END_Boss.Elster` / `BOS_Adler.Elster`; Kolibri dead/intensity (client feedback hit dropped, no double stagger); **join dump ForceFull**; client skips apply while transient + refreshes empty boss cache; Kolibri/Adler Update **Prefix+Postfix** Hold; Falke `Arenas`/shields/corrupt/`SetBodySpearStates` from snap stage/corrupt; END/Chimera/Mynah HaltBossController (StopAllCoroutines); Chimera/Mynah `startFightSequence` blocked on clients |
| Friendly fire | Opt-in (host's toggle) | Default OFF; one ray per live round spent; damage clamped |
| Pause | None in co-op | `NoPausePatch` drops `Time.timeScale = 0` writes (PauseMenu, InventoryBase, ItemPickup view, Dialogue, BookScreen, …) while `NetGate.Party` (network send cadence runs on unscaled time, so no pause can stall sync). No safe menus: `Players/MenuHit` holds a hit taken in inventory / pause / book / event screen / photo viewer, closes that screen natively (ToggleInventory, togglePause, BookScreen.Close, exitEvent, DisableViewer; RestorePlay after 2.5 s) and replays it through HurtElster/Hug once in play. Dialogue: native BlackSleekGuiSubs cancel, answer forced to "no". Solo / lone host = vanilla |
| Inventories | Independent | 6-slot bags stay personal; box + key ring are shared |
